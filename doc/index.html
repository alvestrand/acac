Getting started with ACAC

ACAC is a tool for figuring out all common ancestors for a group of people. This only makes sense if the people are assumed to be related, such as having matching DNA on a specific segment.

There are three steps in finding ancestor groups:

  1. Finding the group of matches
  2. Finding the Geni profiles for the matches
  3. Using ACAC to figure out the common ancestors

Finding a group of relatives

In DNAPainter, one may come across a block that looks like the red block in the image. It's tempting to assume that this indicates descent from a single ancestor. Note the names and whatever other identifying data you have found in DNApainter, and go to the next step.

Finding the Geni profiles

The next step is to find the entries in geni.com corresponding to those matches. This may involve searching, or even finding an ancestor somewhere in the tree and entering the tree from MyHeritage down to the match. In the end you have a profile, and the profile has an URL, as seen in the top of the image. You can also enter the profile's GUID.

Using ACAC to figure out the common ancestors

Now go to ACAC and choose the DNA match group you're working on in the "Group" menu, or create one using the "New group" button. The name should be something you associate with the group, for instance "Harald chr 3 pos 31 mother's side".

Then copy the URL found above, or enter the profile's GUID, in the "Add profile" field. ACAC will then (after asking permission) search Geni for the ancestors of that profile. And if we're lucky, we'll end up with a display like these examples, showing ancestors for this particular segment.

The profiles you're considering appear below the "Add profile" field, and the groups with their common ancestors appear to the right. As you add profiles, those groups may change and their common ancestor lists may shrink. The aim is for the groups to converge on a single set of ancestors that could be the source for that segment.

This means that all the people entered descend from those parents, and one of them (we don't know which) is likely the ancestor for that particular segment. All the links open the profile in a new window.

With "Display path" unchecked, ACAC shows the potential common ancestors followed by the profiles in the group.

Check "Display path" to show all known paths from each profile to each potential common ancestor. Different ancestors can have different paths.

Hit the "save database" button to save your work so far in the browser, or use "save to file" to save the database to a file. Filenames are automatically generated. The database and saved groups are kept in browser storage and should be available after restarting the browser.

You can also use "Save group" to save the information gathered for this group to a file too.

Enjoy!
