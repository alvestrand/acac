# How to find a MyHeritage DNA match on Geni

## Simplest: Look in your DNA matches

Go to your profile, the DNA tab, and click the blue link under
"Autosomal DNA".

If the match has uploaded his/her DNA to Geni, it might be on the
list. There's no search in the list - sort on an appropriate criterion
(likely "name" or "match quality") and scroll down to where it should
have been.

However, this works only for people who have uploaded their DNA to
Geni, which isn't all that great.

## Look for the common connection

If the match has a tree visible on MyHeritage, you can go further. (If
the match doesn't have a tree, your only option is to contact the
match and hope for an answer.)

### Finding the link

Pick a profile old enough to be likely to be public (born before
1875), and search for it using Geni's search facilities. This probably
gives you enough information to decide whether it's there or not;
clicking on the profile link may give you the profile (if it's one in
your family group or one you added) or a message asking you to upgrade
to Geni Pro.

If you get the "upgrade" message, try searching on Google for the
name, with "site:geni.com" in the search. This will often give you the
profile, or a profile that links to that profile. Choosing a profile
with an uncommon name helps here!

(Note that the index of Google and other search engines do NOT contain
all profiles in Geni. You may have to make multiple tries.)

View the tree of that profile. You can now follow the tree down where
it matches the MyHeritage tree.

Sooner or later you will either find the profile, a profile with no
descendants, or a profile that shows up in grey, marked "private".

### When you reach the private profiles

At this point, you need to enter profiles. Simply add what you can
read from the MyHeritage tree, down to the profile you're trying to
reach. For the profiles that are private in the MH tree, add them with
the given name "<private>" - MH will most often show you the family
name, even for private profiles. Mark them living.

Now, enter the profile you're interested in. You now have the profile
with an URL that you can paste into ACAC. Before that, it is good to
enter as much as you can

You are now likely to have blue dots on the profiles, indicating that
they match profiles already in the tree. If you're a Pro member, you
can request those merges; if not, you just have to wait for the
profile owner of the other profile to merge them. Luckily, you *can*
see the administrators of those profiles, and try to contact them.
Some respond very quickly; some respond slowly; many don't respond at
all.

If you feel that you really need the merges requested, contact a
curator for help.

### Extending the tree with more branches

You can repeat this exercise for multiple profiles in the MyHeritage
tree. When you get down to the target profile, you should be able to
merge the ones you entered yourself.

If you extend the tree with more ancestors after adding the profile to
ACAC, you can use the "rebuild tree" function to get ACAC to fetch the
new profiles into ACAC for consideration.
