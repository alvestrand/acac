Geni login test

Logs in to Geni and fetches the logged-in user's profile with plain HTTP, without Geni's jsdk.js. This page is for experiments and is not deployed.

Login works the way jsdk.js does it: a popup opens https://www.geni.com/oauth/authorize with response_type=token, client_id, display=popup, a callback name and this page's origin. No redirect_uri is sent. When the user allows access, the Geni page in the popup sends this page a message with postMessage, holding a query string such as callback=…&access_token=…&refresh_token=…. Only messages from https://www.geni.com with the expected callback are used.
